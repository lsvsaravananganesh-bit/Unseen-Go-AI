✦ Security & Trust

Security & Responsible Disclosure

We take the protection of user accounts, traveler privacy, and location telemetry seriously.

Account & Authentication Architecture

User passwords are encrypted with industry-standard cryptographic salting and hashing (scrypt) before storage. We utilize timing-safe comparisons to prevent timing attacks. Sensitive credentials, database connection strings, and API secrets are managed exclusively through server-side environment variables and are never bundled in client assets.

Responsible Disclosure Policy

If you discover a vulnerability, misconfiguration, or data leakage in UnseenGo AI, please report it to us immediately. We commit to acknowledging receipt within 48 hours and working with you to validate and remediate the issue promptly.

  • Do not attempt to access or modify data belonging to other users.
  • Do not execute denial-of-service (DoS/DDoS) attacks against production infrastructure.
  • Allow reasonable time for remediation before publishing details publicly.
